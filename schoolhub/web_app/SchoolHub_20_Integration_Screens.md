# SchoolHub Integration Screens for ClassroomPro, ExamPro, ResultsPro, TutorsPro, and Scholars.ng

This document lists the **20 integration screens only** for SchoolHub and describes the **insight content** each screen should capture from the connected ecosystem products.

## 1) Student/Classroom Dashboard
**Source:** ClassroomPro  
**Purpose:** Give students a central learning snapshot inside SchoolHub.

**Insights to capture:**
- Today’s lessons and class schedule
- Upcoming homework and submission deadlines
- Attendance status and streaks
- Teacher announcements
- Recent lesson activity and participation level

**Quick actions:**
- Open lesson
- Submit homework
- View class notes
- Message teacher

## Summary
These 20 screens give SchoolHub a clean integration structure:  
- **ClassroomPro** powers daily learning and classroom activity  
- **ExamPro** powers practice and readiness insights  
- **ResultsPro** powers official performance and reporting  
- **TutorsPro** powers tutoring and lesson coordination  
- **Scholars.ng** powers future-skills progression

Together, they create a single SchoolHub experience where every user sees the right snapshot first, then moves into the deeper product only when needed.
