# Roman Numerals I to C and Equivalent Fractions

## Learning Objectives
1. Convert Hindu-Arabic numerals ($1$ to $100$) to Roman numerals ($\text{I}$ to $\text{C}$) and vice versa.
2. Generate equivalent fractions by multiplying or dividing the numerator and denominator by the same non-zero number.
3. Reduce fractions to their lowest terms.

## 1. Key Roman Numeral Symbols
| Symbol | Value |
| :---: | :---: |
| $\text{I}$ | $1$ |
| $\text{V}$ | $5$ |
| $\text{X}$ | $10$ |
| $\text{L}$ | $50$ |
| $\text{C}$ | $100$ |

- **Addition Rule**: $\text{LX} = 50 + 10 = 60$; $\text{LXXIV} = 50 + 20 + 4 = 74$.
- **Subtraction Rule**: $\text{XL} = 50 - 10 = 40$; $\text{XC} = 100 - 10 = 90$.

![Visual Fraction Strips Showing Equivalent Fractions](asset://cld-pri4-math-fractions-diagram)

## 2. Equivalent Fractions
Two fractions are equivalent if they represent the same part of a whole:
$$\frac{1}{2} = \frac{2}{4} = \frac{3}{6} = \frac{4}{8}$$

## 3. Exercises
1. Express $49$ and $94$ in Roman numerals.
2. Find the missing numerator: $\frac{3}{5} = \frac{?}{20}$.
